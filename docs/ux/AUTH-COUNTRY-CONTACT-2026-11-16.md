# Registration country and contact presentation — local candidate

Preserves the approved artwork, official ATRY logo, form fields, two-step flow, auth transition, native validation and existing backend contracts. Replaces the plain country dropdown with two compact native radio choices (Uruguay / Panamá), displaying currency and a checked mark. Keeps one `country` value in FormData. Existing country immutability and server PA readiness gate remain intact. Additional-business creation reuses the visual control but does not infer a country from the visitor.

Only initial registration suggests the country: explicit registration preference > existing server-rendered visitor-country meta, if provided > exact browser IANA zone America/Panama or America/Montevideo > Uruguay. Browser language and UTC offset are not used. No geolocation permission, external IP service, tracking or extra network call is introduced. The existing hosting does not provide a geographic hint to this auth page, so its ordinary automatic fallback is IANA, not verified physical location. A traveller can always choose the actual business country manually. Only that manual choice is persisted in `atry.registration.country.v1`, independently of marketing and existing businesses. Late config never overrides a manual choice. Failure to confirm server readiness closes PA rather than enabling it.

Three circular contact links share the exact #4754E6 → #6250DF artwork gradient, 44px touch targets, familiar monochrome marks and keyboard focus. Destinations: mailto:atryagency@gmail.com; https://www.instagram.com/atryagency/ (owner supplied); https://wa.me/59893802328 (existing source). These are clearly labelled contact links, never OAuth/social sign-in. No new authentication provider or permission. SVG geometry from Simple Icons is stored locally with source/license attribution; no icon package or runtime dependency.
